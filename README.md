# 📊 Web Scraping Dashboard

A Python-based web scraping dashboard built with Streamlit.  
The application collects book data from the web and displays it in an interactive dashboard.

## ✨ Features

- 🔄 Scrape book data from the web
- 🔍 Search books by title
- 💰 Filter books by maximum price
- ↕️ Sort books by price
- 📚 Display total number of books
- 💵 Calculate average and maximum price
- 📊 Visualize book prices using a bar chart
- 📋 Display scraped data in a table
- ⬇️ Download data as a CSV file

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Requests
- BeautifulSoup
- HTML/CSS concepts
- Git & GitHub
